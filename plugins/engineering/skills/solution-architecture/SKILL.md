# Solution architecture

Capture context, constraints, options, decision, consequences, and evidence.
Evaluate correctness, security, operability, performance, availability, cost,
and maintainability. Validate uncertain claims with a bounded isolated spike,
not a production change. Record decisions as non-destructive
`docs/adr-<number>-<short-title>.md` files using existing project conventions.
